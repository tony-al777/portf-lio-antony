
Site pessoal responsivo de 3 páginas desenvolvido para apresentação profissional e entrega acadêmica no curso Técnico em Desenvolvimento de Sistemas (**SENAI PE / Areias**).

### Páginas do site
- `index.html` — **Início**: apresentação profissional, objetivo, conhecimentos técnicos, formação acadêmica e cursos adicionais.
- `projetos.html` — **Projetos**: tabela comparativa de projetos e cartões detalhados com tecnologias e links externos.
- `contato.html` — **Contato**: canais diretos (e-mail, LinkedIn, GitHub) e formulário com 7 campos, labels e validação nativa.

## Tecnologias utilizadas

- **HTML5 Semântico**: `header`, `nav`, `main`, `section`, `footer`, listas, tabela acessível e formulário com validação nativa.
- **CSS3**: variáveis em `:root` (paleta de 3 cores + tema escuro), Box Model, Flexbox, transições e layout responsivo com `@media (max-width: 600px)`.
- **JavaScript (opcional para tema)**: alternância de tema claro/escuro com persistência em `localStorage`.

## Como abrir o site

1. Clone ou baixe este repositório:
   ```bash
   git clone https://github.com/tony0089/portfolio-antony.git
   ```
2. Entre na pasta do projeto e abra o arquivo `index.html` diretamente no navegador (ou utilize a extensão **Live Server** no VS Code).
